# Development roadmap

| Stage | Evidence needed |
| --- | --- |
| Data preparation | Permissions, labeling guide, group-based split, and examples reviewed by growers or experienced pruners |
| Perception baseline | Reproducible training, held-out evaluation, and a record of misses and false detections |
| Pruning review | Expert agreement and disagreement cases, tested abstention behavior, and a documented human override |
| Offline inference | Local export, output parity, and measured performance with networking disabled |
| Off-the-shelf glasses MVP | Supported camera and display SDKs, readable cues, measured alignment, and sustained-use battery and thermal measurements |
| Orchard evaluation | Consenting participants and a predefined protocol for decision quality, worker usability, and failure reporting |

The challenge recognized the concept. Any product-performance claim should cite results from the relevant stage.
